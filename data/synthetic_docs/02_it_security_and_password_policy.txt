Classification: INTERNAL CONFIDENTIAL (MEDIUM SENSITIVITY)

Version: 4.1

1. OBJECTIVE
To establish baseline security requirements for safeguarding corporate IT assets, corporate networks, 
workstations, and cloud credentials against unauthorized intrusion and credential compromise.

2. AUTHENTICATION & PASSWORD COMPLEXITY
2.1 All system credentials and enterprise network logins must satisfy the following minimum criteria:
    - Minimum length: 14 characters.
    - Must contain uppercase letters, lowercase letters, numeric digits, and special characters (!@#$%^&*).
    - Dictionary words, common sequences (e.g., 'Company2026!'), and past 6 passwords cannot be reused.
2.2 Mandatory password rotation is enforced every 90 calendar days.
2.3 Multi-Factor Authentication (MFA) via hardware security keys or authenticator apps (TOTP) 
    is strictly mandatory for all external VPN and cloud application access. SMS-based 2FA is prohibited.

3. ENDPOINT AND WORKSTATION HYGIENE
3.1 Screen locks must engage automatically after 5 minutes of inactivity.
3.2 Employees must never write down credentials or store passwords in unencrypted local text files or notes.
3.3 Corporate laptops must utilize full-disk encryption (BitLocker / FileVault) enabled by IT administration.
3.4 Installation of unauthorized third-party software, browser plugins, or peer-to-peer applications is strictly prohibited.

4. REMOTE WORK & VPN ACCESS
4.1 Remote employees accessing internal repositories must connect exclusively through the Corporate WireGuard VPN.
4.2 Split-tunneling is disabled on corporate devices by default.
4.3 Public Wi-Fi networks (cafes, airports) must never be utilized without an active corporate VPN connection.

5. INCIDENT REPORTING
5.1 Suspected phishing emails, anomalous password prompts, or device theft must be reported within 1 hour 
    to the Security Operations Center at soc-alerts@acme.internal or phone extension 5599.
